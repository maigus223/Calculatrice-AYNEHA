# Calculatrice AYNEHA

Calculatrice web en **chiffres AYNEHA**, avec saisie et affichage de droite à gauche. Une démonstration de l'écriture « en action ».

*Web calculator using AYNEHA digits, with right-to-left input and display.*

**En ligne / Live : https://maigus223.github.io/Calculatrice-AYNEHA/**
Site officiel : https://ayneha.org

## Utilisation
- Pavé tactile ou clavier d'ordinateur : chiffres, `+ - * /`, `Entrée` ou `=`, `Retour arrière`, `Échap` (tout effacer), `.` ou `,` (virgule)
- Le zéro AYNEHA est dessiné comme un rectangle : ce n'est pas un caractère manquant
- Les milliers sont séparés par un petit point orange ; la virgule décimale est un rond posé en bas
- Jusqu'à 15 chiffres ; au-delà, la calculatrice affiche « Erreur »
